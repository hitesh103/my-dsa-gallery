# Jump Game II

Problem link: <Link href={meta.link}>{meta.link}</Link>

## Problem Statement

You are given an array `nums` where `nums[i]` is the maximum jump length from index `i`.  
Starting at index `0`, return the **minimum number of jumps** needed to reach the last index.

## Input

- `nums`: integer array

## Output

- Minimum jumps to reach `n - 1`

## Example

```txt
nums = [2, 3, 1, 1, 4]
output = 2
```

Explanation: jump `0 -> 1` (max reach grows), then `1 -> 4`.

## Brute Force

### Intuition

If we know the best answer to reach smaller indices, we can build the best answer for later indices.

### Approach (DP)

Let `dp[i]` be the minimum jumps to reach index `i`.  
For each `i`, try all `j < i` that can reach `i`.

### Code (Java)

```java
import java.util.Arrays;

public class JumpGameIIBruteForce {
    public static int jump(int[] nums) {
        int n = nums.length;
        int[] dp = new int[n];
        Arrays.fill(dp, (int)1e9);
        dp[0] = 0;

        for (int i = 1; i < n; i++) {
            for (int j = 0; j < i; j++) {
                if (j + nums[j] >= i) {
                    dp[i] = Math.min(dp[i], dp[j] + 1);
                }
            }
        }
        return dp[n - 1];
    }
}
```

<ComplexityBadge time="O(N^2)" space="O(N)" />

### Complexity Analysis (with explanation)

- **Time `O(N^2)`**: for every `i`, you scan all earlier `j`.
- **Space `O(N)`**: the DP array stores answers for all indices.

## Optimal Solution

### Intuition

Every index you can reach with `k` jumps forms a **range**.  
From that range, one more jump can expand to a new range.

This is BFS by “levels”, but we can do it greedily by tracking:

- `currentEnd`: end of the current jump range
- `farthest`: farthest index reachable from within the current range

### Approach (Greedy range tracking)

Scan once, maintaining the current “level” end.

### Code (Java)

```java
public class JumpGameIIOptimal {
    public static int jump(int[] nums) {
        int n = nums.length;
        if (n <= 1) return 0;

        int jumps = 0;
        int currentEnd = 0;
        int farthest = 0;

        for (int i = 0; i < n - 1; i++) {
            farthest = Math.max(farthest, i + nums[i]);

            // We reached the end of the current jump range: take a jump.
            if (i == currentEnd) {
                jumps++;
                currentEnd = farthest;
            }
        }
        return jumps;
    }
}
```

<ComplexityBadge time="O(N)" space="O(1)" />

### Complexity Analysis (with explanation)

- **Time `O(N)`**: each index is processed once.
- **Space `O(1)`**: only a few pointers/counters are used.
